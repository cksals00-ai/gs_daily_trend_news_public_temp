# AP Safe · AP Travel — 홈페이지 개발자 전달 가이드

작성 기준: 2026-09-23 · 공개 홈페이지용 · 작동 파일럿

## 1. 연결 주소

| 서비스 | 서비스 시작 버튼 | 로그인 없이 보는 합성 예시 |
|---|---|---|
| AP Safe | https://revenue.apholdings.kr/safe/ | https://revenue.apholdings.kr/safe/?demo=1 |
| AP Travel | https://revenue.apholdings.kr/travel/ | https://revenue.apholdings.kr/travel/?demo=1 |

현재 두 서비스는 같은 AP 플랫폼 도메인 아래 별도 경로로 운영됩니다. `safe.apholdings.kr`, `travel.apholdings.kr`로 임의 변경하지 마세요. 기존 AP 조직 계정을 공통으로 사용합니다. 예시 화면은 로그인 없이 열리며, 실제 판단 실행·저장은 로그인과 조직 권한이 필요합니다.

기존 홈페이지의 한국어·영어 메인과 각 제품 페이지에는 바로가기 연결이 반영되어 있습니다. 이번 자료는 해당 연결을 유지하면서 소개 문구·이미지를 정리하는 데 사용하세요.

## 2. 홈페이지에 바로 사용할 문구

### AP Safe

**제목**  
추천 전에, 충돌 조건부터 확인하세요.

**카드 소개**  
제품 구성과 사용자 회피·주의 조건을 비교하고, 대체 후보에도 같은 기준을 적용합니다.

**상세 설명**  
추천에서 제외할 충돌 조건과 추가 확인이 필요한 정보를 구분합니다. 담당자는 판단 근거를 확인하고 수락·수정·거절 및 관측 결과를 기록할 수 있습니다.

**핵심 기능**
- 회피·주의 조건과 제품 구성의 명시적 일치 확인
- 정보 부족 시 추가 검토로 보류
- 대체 후보에 동일 조건 적용
- 엑셀 입력, 판단 근거와 담당자 검토 기록

**주 버튼:** AP Safe 시작하기  
**보조 버튼:** 합성 예시 보기  
**상태 배지:** 작동 파일럿  
**항상 함께 표시할 문구:** 입력된 조건과 구성정보를 비교하는 검토 도구입니다. 의료진단·절대적 안전보증이 아닙니다.

### AP Travel

**제목**  
다음 캠페인을, 어느 시장에 집중할까요?

**카드 소개**  
여행 수요·항공 공급·예약 등 시장 신호를 함께 검토해 공략할 시장과 보완할 근거를 정리합니다.

**상세 설명**  
출발 시장·목적지·여행 기간별 자료를 입력하면 우선 공략 검토, 관찰·보완, 우선순위 축소로 분류합니다. 판단 근거와 다음 행동을 확인하고 담당자의 결정과 관측 결과를 축적합니다.

**핵심 기능**
- 시장 신호 8개와 출처·기준일 확인
- 공급 제약·수요와 예약 방향의 상충 검토
- 엑셀 입력과 시장별 판단 기록
- 같은 시장·여행 기간의 자료 갱신 전후 비교

**주 버튼:** AP Travel 시작하기  
**보조 버튼:** 합성 예시 보기  
**상태 배지:** 작동 파일럿  
**항상 함께 표시할 문구:** 규칙 기반의 시장 검토 도구입니다. 점수는 매출 예측이나 성과 보장이 아닙니다.

## 3. 이미지 파일과 사용법

| 파일 | 규격 | 권장 위치 |
|---|---|---|
| images/AP_Safe_Synthetic_Example.jpg | 1348 × 1195 px, JPEG | Safe 상세 페이지의 기능 설명 아래 |
| images/AP_Travel_Synthetic_Example.jpg | 1348 × 1195 px, JPEG | Travel 상세 페이지의 기능 설명 아래 |

실제 공개 합성 예시 화면의 전체 캡처입니다. 임의로 생성한 서비스 화면이 아닙니다. 모든 제품·시장·수치는 예시이며 실제 고객사 실적이 아닙니다. Safe 이미지는 ‘추천 제외 / 추가 검토 / 명시적 충돌 없음’을, Travel 이미지는 ‘우선 공략 검토 / 관찰·보완 / 우선순위 축소’를 보여줍니다.

- 원본 비율을 유지하고 `width:100%; height:auto`로 표시하세요.
- `object-fit:cover`로 상단의 합성 데이터 표시를 잘라내지 마세요.
- 화면 속 글자를 읽게 하려면 상세 페이지에서 한 번에 한 이미지를 가로폭 960px 내외로 배치하세요.
- 작은 홈 카드에서는 이미지를 썸네일로 쓰고, 클릭하면 합성 예시 페이지로 이동하게 하세요.
- 모바일에서는 글자를 과도하게 축소해 읽도록 요구하지 말고 ‘예시 화면 크게 보기’ 링크를 함께 제공하세요.
- 이미지 아래에도 `합성 데이터 기반 화면 예시 · 실제 제품·시장 판정이 아닙니다.`를 적어 주세요.
- 실제 회사명·개인정보·소노 실적 자료로 이미지를 교체하지 마세요.

**Safe 이미지 alt**

## 4. 추천 페이지 배치

제품명·파일럿 배지 → 제목·짧은 소개 → 시작하기 / 합성 예시 보기 → 예시 이미지·캡션 → 현재 기능 → 사용 범위·진행 상태

메인 홈페이지에서는 Safe와 Travel을 기존 Decision Intelligence 영역에 배치하고, Revenue와 버튼 규칙을 맞춥니다. 별도의 로그인 폼을 홈페이지에 복제하지 않습니다. 계정 정보나 인증 키를 링크·스크립트·이미지에 포함하지 않습니다.

`homepage-section.html`은 복사 가능한 시맨틱 HTML과 반응형 스타일 예시입니다. 파일을 열어 문구·버튼·이미지 배치를 확인한 후 기존 홈페이지의 디자인 토큰에 맞춰 적용하세요. 이미지 경로는 사이트의 실제 배포 디렉터리에 맞춰 수정합니다.

## 5. 구현된 기능과 후속 작업의 구분

| 구분 | 현재 제공 | 후속 연결·검증 |
|---|---|---|
| Safe | 직접·엑셀 입력, 명시적 충돌 검토, 대체 후보 재검토, 판단·검토 기록 | 검증된 제조사 제품 데이터·동의어 사전·앱 자동 연동 |
| Travel | 직접·엑셀 입력, 8개 신호·출처 검토, 시장 판단·이력 비교 | 외부 시장 데이터 자동 수집, 지표 정의 표준화, 실제 성과에 따른 검증 |
| 공통 | 조직 계정·권한, 분석자 입력, 승인자·관리자 검토 | 실제 조직 계정으로 전체 저장·승인 흐름의 최종 사용 검증 |

공개 소개에는 ‘외부 원천 자동 연동 완료’, ‘검증된 예측 정확도’, ‘100% 안전’, ‘자동 매출 향상’, ‘자동 가격 변경’으로 표현하지 않습니다. 현재 웹 파일럿과 기존 Safelist 앱·커넥터는 제공 범위가 다르므로 자동으로 연결되어 있다고 설명하지 않습니다.

## 6. 게시 완료 확인

1. Safe·Travel의 시작 버튼이 위의 정확한 서비스 경로로 연결되는지 확인합니다.
2. 합성 예시 버튼은 `?demo=1`을 유지하고 로그인 없이 보이는지 확인합니다.
3. 휴대폰에서 이미지·버튼이 화면 밖으로 넘치지 않는지 확인합니다.
4. 이미지 안팎의 합성 예시 표시와 각 서비스의 사용 범위 문구를 유지합니다.
5. 이미지의 alt와 width/height를 지정하고, 화면 아래 이미지는 lazy loading을 적용합니다.
6. 사용자 입력 화면과 공개 합성 예시를 혼동하지 않도록 버튼 이름을 구분합니다.

## 7. 이번 개발 연속 작업

Travel 자료 갱신 전후의 8개 지표·출처·판정 비교, 비교 조건 불일치 차단, 규칙 버전 변경 시 점수 차이 보류를 추가했습니다. 대상 여행 기간 누락 시 WATCH, 잘못된 지표값은 미확인, 미래·존재하지 않는 결과 측정일은 저장 차단하도록 보강했습니다. Safe는 공백 차이로 중복되는 후보 ID를 차단합니다. 화면 이미지는 검토 현황을 보여주며 이력 비교 기능 자체의 스크린샷은 아닙니다.
