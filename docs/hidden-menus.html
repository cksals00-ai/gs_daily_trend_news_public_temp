숨김 메뉴 관리ADMIN ONLY

메인 네비게이션에서 감춘(미사용) 메뉴 모음입니다. 페이지 파일은 보존되어 있어 아래 열기로 직접 접근할 수 있고, 다시 노출 토글로 이 브라우저에서 메뉴를 임시로 되살릴 수 있습니다.

다시 노출하는 방법

  • 임시(이 브라우저만): 각 항목의 다시 노출 토글 → 즉시 메뉴가 다시 보입니다. 설정은 localStorage('gsn_menu_overrides') 에 저장되며 이 기기/브라우저에만 적용됩니다.
  • 영구(전체 사용자): docs/js/menu-visibility.js 의 GSN_HIDDEN_MENUS 목록에서 해당 항목을 삭제한 뒤 배포하면 모든 사용자에게 다시 노출됩니다. 이 파일이 숨김 메뉴 정의의 단일 소스입니다.
