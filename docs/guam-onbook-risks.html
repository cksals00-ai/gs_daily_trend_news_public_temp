엑셀 수기 수정은 계산 오류와 비교 기준의 혼선을 만들 수 있습니다

현재 파일에서는 매출 셀의 인원 참조, Total의 합산 기간 차이, 비교 기준일 표기 불일치를 확인했습니다. 파일의 수정 이력은 없으므로 오류가 언제 누구의 수정으로 발생했는지는 판단할 수 없습니다. 현재 수식으로 확인한 문제와 향후 수기 수정에서 발생할 수 있는 위험을 구분합니다.

값이 정상이어도 계산이 틀릴 수 있음

인원 합계를 매출 셀에 넣어도 Excel 오류는 발생하지 않습니다. 숫자·수식·단위를 함께 확인해야 합니다.

전체 합계가 비슷해도 기간은 다를 수 있음

기존 Total은 9~11월, 현재 원천은 10~12월입니다. 같은 ‘Total’이라는 이름으로 비교하면 기간 차이를 놓칩니다.

자동화 이후에도 보정 근거가 필요함

현재 수식에 남은 예외 규칙은 보존할 수 있습니다. 결과값을 직접 덮어쓴 수정은 사유·대상·기준일 기록 없이는 재현할 수 없습니다.

목표·예산 수정은 허용된 입력입니다. 원천 실적 수정은 다른 성격의 행위입니다. 실적 보정이 필요하면 자동 계산을 덮어쓰지 않고 원천 값, 보정값, 최종 값을 함께 보관해야 합니다. 현재 파일에는 그런 보정 이력이 없어, 실제 과거 보정값을 임의로 만들지는 않습니다.

예약 현황을 해석할 때

  • 10월 7일의 10~12월 예약은 아직 기간이 끝나지 않은 현황입니다. 월 목표 대비 비율은 예약 확보율로 볼 수 있지만 마감 실적 달성률로 단정할 수 없습니다.
  • 월별 남은 기간과 예약 선행 기간이 다릅니다. 확보율 차이만으로 원인을 여행사 영업 또는 가격에 돌릴 수 없습니다.
  • 라운드당 매출 차이는 회원·여행사·로컬 구성과 상품 차이를 포함합니다. 동일 상품의 가격 차이로 해석하지 않습니다.
  • 하나의 기준일 자료로 예약 증가 속도·취소율·순증 추세를 계산할 수 없습니다. 같은 조회 기간의 다음 스냅샷이 필요합니다.
  • 9홀·18홀·패키지 유형과 관계없이 현재 보고서 규칙은 예약 1행을 1라운드로 셉니다. 18홀 환산 라운드가 아닙니다.
분석 근거와 한계

근거는 사용자 제공 Golfmanager 판매 파일, 2026년 10월 7일 DAILY ON BOOK STATUS의 수식·저장값·raw data, 시스템 예약 내보내기 컬럼 비교입니다. 10~12월 월·시설·분류별 PAX/REV 612개 값을 원천 재집계와 대조했습니다. 파일 내 외부 링크 정의는 10개지만 현재 수식에 직접 외부 파일 참조는 없어 현재 숫자의 외부 링크 의존 오류는 확인되지 않았습니다. Excel 오류 값이 없다는 사실이 잘못된 참조나 비교 기준 혼선을 없애지는 않습니다.

수기 변경의 작성자·시간·이전 값은 이 파일에 없습니다. 확인된 오류와 잠재 위험은 구분했으며, 금전적 손실·부정행위·실제 과거 수정 행위는 추정하지 않았습니다.
