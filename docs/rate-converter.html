4미리보기

고정 변환 기준

  1. 양식: 파란 제목 헤더 → 투숙/상품/노트 → 부대 요약 1줄 → 메인표(기간·시즌·구분·객실·부대·판매가·비고) → 시즌 정의. 맑은 고딕, 헤더 D9D9D9·시즌 F2F2F2·기간 E2EFDA, thin 테두리, 기간은 블록 전체 병합.
  2. 가격: 무기명/FIT 배분 분리, 회원 할인율 표기(무기명 정상 대비), GAP=FIT−무기명, 부대 회원=FIT GAP0.
  3. 부대: 패키지 구성 전체(조식 포함). 판매가=객실배분+부대배분.
  4. 공통: 단위 천원, 전 객실타입 기간×시즌 MIN~MAX, 할인율 endpoint(정상MIN vs 배분MIN / MAX vs MAX).
  5. 원칙: 실제 셀 값만, #REF!/오류 컬럼 미사용·직접 산출.

도움말

· 변환은 브라우저 안에서만 실행되며 파일이 외부로 전송되지 않아.
· 결과 xlsx는 서식(색·병합·테두리) 포함.
· 자동감지가 틀리면 매핑 드롭다운으로 수정 후 다시 변환.
