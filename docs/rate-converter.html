요금표 → 품의 배분가(안) 변환기

브라우저에서 양식을 자동 인식하고 역산검증(판매=객실배분+부대배분)으로 오류를 걸러 GS 품의 양식으로 변환합니다. · 서버 불필요

1요금표 업로드

xlsx 파일을 끌어다 놓거나 클릭 — 채널/사업장 무관, 양식 달라도 자동 인식

2변환 기준 (자동)

· 회원 = 무기명 / FIT = FIT·카카오·인플루언서·OTA 자동감지
· 시즌: 하이1·2→하이, 골드3·4→스페셜(추석), 주중(일)→주중, 전 객실타입 MIN~MAX
· 부대배분 = 판매 − 객실배분(역산), 정상요금 컬럼 있으면 부대정상까지 산출
· 역산 불일치·매핑 실패 시 변환하지 않고 안내 (잘못된 품의 방지) — 그런 파일은 담당(Claude)이 수동 처리
· 여러 상품 시트면 가장 큰 시트 자동 선택 · 결과는 섹션4(배분가) 채움
