원하는 이용 기간의 예약 전체를 내려받아 맥 입력 폴더에 넣습니다. 프로그램은 파일 날짜를 기준일로 사용하고, 이용월별 예약과 목표를 비교합니다.

월별 다운로드

범위가 넓으면 Start date를 한 달씩 설정합니다. Creation date 조건은 해제하고 취소도 포함합니다. 저장된 보기 때문에 일부 열만 나오지 않도록 내보낸 파일에 Id·Start date·Total·Type·typeName·clientName·clientGroupName·Nationality가 있는지 확인합니다.

최초 전체 이력은 01_raw/bookings/monthly에 보관합니다. 이후 10~12월은 매일 같은 이용일 범위로 받습니다. 기준일은 다운로드한 날짜입니다.

매일 월별 파일을 받는 경우

세 파일을 같은 기준일로 받아 아래 이름으로 01_raw/bookings/monthly에 저장합니다. 업데이트 프로그램이 세 파일이 모두 도착한 뒤 합칩니다. 서로 다른 다운로드 날짜는 섞지 않습니다.

  • bookings_2026-10_asof_2026-10-09.xlsx
  • bookings_2026-11_asof_2026-10-09.xlsx
  • bookings_2026-12_asof_2026-10-09.xlsx

뒤의 날짜는 실제 다운로드 날짜로 바꿉니다. 이후 업데이트.command를 실행합니다. 전체 기간을 한 번에 받은 파일도 기존 방식으로 사용할 수 있습니다.

실행 순서

  1. 왼쪽 Billing → Bookings를 엽니다. 상단의 Breakdown으로 행별 목록을 확인합니다.
  2. 현재 Creation date 조건이 있으면 지웁니다. 예약 검색 조건에 Start date 기간과 Cancelled 조건 해제를 설정합니다. 두 골프장과 전체 채널이 포함됐는지 확인합니다.
  3. 목록의 … → Export to excel을 선택합니다. 받은 파일의 시트는 Booking이며 Id, Start date, resourceTypeName, Total 컬럼이 있어야 합니다.
  4. 이름을 bookings_2026-10-08.xlsx처럼 바꿔 외장하드 맥북프로26/SONO_GUAM_DB/01_raw/bookings에 저장합니다. 파일명 날짜는 실제 조회 기준일입니다. 다른 기간 파일을 합쳐 넣지 않습니다.
  5. 목표가 바뀌었으면 같은 폴더의 targets.xlsx를 수정해 저장합니다. 비어 있는 목표는 0으로 채우지 않습니다.
  6. 업데이트.command를 더블클릭합니다. 폴더감시.command를 실행해 둔 동안에는 변경된 예약 또는 목표 파일을 감지합니다.
  7. 로컬 미리보기에서 기준일·이용 기간·골프장 합계·미분류를 확인합니다. 로컬 갱신은 맥에 저장된 집계 파일을 갱신합니다. 현재 웹 반영은 확인된 집계 파일을 게시하는 별도 단계입니다.

폴더와 파일 이름

외장하드 맥북프로26/SONO_GUAM_DB/ ├── config.json 이용 기간과 출력 위치 ├── 업데이트.command 한 번 갱신 ├── 폴더감시.command 실행 중 자동 감지 ├── 01_raw/bookings/ │ ├── bookings_2026-10-07.xlsx 지난 기준일 예약 │ ├── bookings_2026-10-08.xlsx 새 기준일 예약 │ └── targets.xlsx 목표·예산·전년 수치 ├── 02_history/ 날짜별 집계 이력 ├── 03_dashboard/ 집계 출력 ├── 04_guides/ 다운로드·리스크 안내 └── scripts/ 처리 프로그램

가장 최신 날짜의 예약 파일 하나를 사용합니다. 여러 파일의 예약을 더하지 않습니다. 하루에 다시 다운로드하면 같은 날짜 파일을 교체하고, 다른 날짜 파일은 보관합니다.
