Golfmanager 예약 다운로드 가이드

원하는 이용 기간의 예약 전체를 내려받아 맥 입력 폴더에 넣습니다. 프로그램은 파일 날짜를 기준일로 사용하고, 이용월별 예약과 목표를 비교합니다.

1 · 시스템 메뉴Billing
2 · 예약 목록Bookings
3 · 행별 예약Breakdown
4 · 목록의 … 메뉴Export to excel
5 · 맥 입력 폴더inbox

Lines sold는 사용하지 않습니다. 현재 판매 화면의 Creation date 필터는 판매 생성일입니다. 같은 기간이라도 예약의 Start date 기준 숫자와 다릅니다.

실행 순서

  1. 왼쪽 Billing → Bookings를 엽니다. 상단의 Breakdown으로 행별 목록을 확인합니다.
  2. 현재 Creation date 조건이 있으면 지웁니다. 예약 검색 조건에 Start date 기간과 Cancelled=No를 설정합니다. 두 골프장과 전체 채널이 포함됐는지 확인합니다.
  3. 목록의 … → Export to excel을 선택합니다. 받은 파일의 시트는 Booking이며 Id, Start date, resourceTypeName, Total 컬럼이 있어야 합니다.
  4. 이름을 bookings_2026-10-08.xlsx처럼 바꿔 inbox에 저장합니다. 파일명 날짜는 실제 조회 기준일입니다. 다른 기간 파일을 합쳐 넣지 않습니다.
  5. 목표가 바뀌었으면 같은 폴더의 targets.xlsx를 수정해 저장합니다. 비어 있는 목표는 0으로 채우지 않습니다.
  6. 업데이트.command를 더블클릭합니다. 폴더감시.command를 실행해 둔 동안에는 변경된 예약 또는 목표 파일을 감지합니다.
  7. 로컬 미리보기에서 기준일·이용 기간·골프장 합계·미분류를 확인합니다. 웹 반영은 대시보드 통합 후 정해진 배포 단계로 진행합니다.

폴더와 파일 이름

local/guam-onbook/ ├── config.json 이용 기간과 출력 위치 ├── 업데이트.command 한 번 갱신 ├── 폴더감시.command 실행 중 자동 감지 ├── inbox/ │ ├── bookings_2026-10-07.xlsx 지난 기준일 예약 │ ├── bookings_2026-10-08.xlsx 새 기준일 예약 │ └── targets.xlsx 목표·예산·전년 수치 └── history/ 날짜별 집계 이력

가장 최신 날짜의 예약 파일 하나를 사용합니다. 여러 파일의 예약을 더하지 않습니다. 하루에 다시 다운로드하면 같은 날짜 파일을 교체하고, 다른 날짜 파일은 보관합니다.

시스템에서 당시 적용했던 모든 검색 조건은 파일에 저장되지 않습니다. 위 조건은 확인된 보고서 집계 기준을 재현하기 위한 추출 조건이며, 조회 화면에서는 기간과 활성 필터를 함께 확인해야 합니다.
