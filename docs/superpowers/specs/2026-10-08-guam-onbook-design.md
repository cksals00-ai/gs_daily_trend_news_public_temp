# 괌 On Book 데이터 자동화

승인된 사용자 흐름: Golfmanager 예약 Breakdown 엑셀을 맥 폴더에 넣고 Python으로 파싱한 후, 기존 괌 대시보드가 완성되면 리포트를 연결한다.

## 범위
- `local/guam-onbook/inbox`에 완전한 조회 범위의 `bookings_YYYY-MM-DD.xlsx`를 저장한다. 날짜는 조회 기준일이며 파일 수정일로 추정하지 않는다.
- 같은 폴더의 `targets.xlsx`는 목표·예산·전년 값을 관리한다. 기존 보고서의 고정값을 초기값으로 사용할 수 있다.
- 월·골프장·고객/채널 집계는 확인된 엑셀 기준을 따르되, 미분류를 별도 표시하여 원천 전체 합계와 대조한다.
- 원천 고객 개인정보는 로컬에만 저장하고 웹에는 집계만 생성한다. 로우와 생성된 실적 데이터는 Git 추적 대상에서 제외한다.
- 조회 범위를 설정 파일에 명시한다. 전후 범위가 같을 때만 증감을 표시하고 전일이 아니면 ‘이전 기준일 대비’로 명시한다.
- 폴더 감시는 수동 실행 가능한 프로그램으로 제공한다. 시스템 시작 시 자동 실행 등록은 하지 않는다.
- 기존 `docs/overseas.html`에는 USD 예약 리포트 링크를 추가하는 검토용 변경만 준비한다. 배포는 기존 대시보드 작업 완료 후 통합한다.

## 검증
취소 제외, 생성일 무관, 연도 구분, 예약 중복·잘못된 판매 파일 거부, 미분류 보존, 목표 입력값 검증, 이전 스냅샷 비교를 테스트한다. 2026-10-07 보고서의 10~12월 월·골프장별 합계 및 세부분류를 대조한다.

## 알려진 차이
원본 Total은 9~11월이며 12월을 제외한다. 웹 합계는 사용자가 선택한 기간을 정확히 표시한다. Z14의 인원 참조 오류는 웹에 이식하지 않는다. 9월은 원천이 없어 초기 비교 이력에 포함하지 않는다. 예약 매출은 수납액이 아니라 예약 Total이다.
